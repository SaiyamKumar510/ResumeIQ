Python Developer

About the role
We are hiring a Python Developer to build and maintain backend services for our logistics platform. You will work closely with the product team and other engineers in an Agile environment.

Responsibilities
- Design and develop RESTful APIs using Python and Django or Flask.
- Write clean, testable code and unit tests with pytest.
- Model and query data in PostgreSQL and optimise slow queries.
- Containerise services with Docker and deploy them through CI/CD pipelines.
- Use Git for version control and participate in code reviews.

Requirements
- 2+ years of professional experience with Python.
- Hands-on experience with Django or Flask and REST APIs.
- Working knowledge of PostgreSQL and Linux.
- Good understanding of data structures and algorithms.
- Familiarity with AWS and Redis is a plus.
